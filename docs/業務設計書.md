# 業務設計書

2026-10-17の「日常のイラッを撃つと、アホな解決をする、戦わなくていいFPSもどき」を現行仕様とする。SwiftUI・RealityKitの既存実装を拡張する。

## 1. 遊びの基本

人物関係や長い物語は設けない。通知や締切などの困りごとをコミカルな立体キャラクターにし、命中するたび困りごとが解消に近づく。プレイヤーへの攻撃・ダメージ・流血・ゲームオーバーはない。

既存の一人称カメラ、スワイプでの視点操作、ジョイスティック移動、18発の射撃、即時リロードを継承する。床・壁・箱の衝突、最初に当たった物体だけに命中するRay判定も継承する。命中は+100点、命中率と2秒以内の連続命中コンボを集計する。

## 2. 全10ステージ

各キャラを指定回数撃ち、全員を解決するとクリア。画面上部に短い説明・条件・解決数を常時表示する。ステージ1は以前の訓練場の配置を使用する。

| Stage | キャラ | 命中と決着 | 1体の必要命中 / 制限時間 |
| --- | --- | --- | --- |
| 1 | 通知スライム | バッジが弾け「静かですね」 | 1 / 35秒 |
| 2 | あと5分ふとん | ふくらんで起き「出勤します…」 | 2 / 40秒 |
| 3 | ぐるぐる読み込み | 進捗100％、「特に何もありませんでした」 | 3 / 45秒 |
| 4 | 絡まるケーブル蛇 | ほどけてきれいな輪になる | 3 / 45秒 |
| 5 | 未読メールゴーレム | 紙が舞い「全部、承知しました」 | 3 / 50秒 |
| 6 | 月曜カレンダー | 月〜金へ進み、サングラスをかける | 4 / 50秒 |
| 7 | 充電1％ロボ | 満タンになり、プレイヤーへ充電ケーブルを向ける | 4 / 55秒 |
| 8 | パスワード門番 | 条件を出し続け、最後は「顔パスでどうぞ」 | 4 / 55秒 |
| 9 | ちょっとだけタスク | 4枚まで見た目が分裂し、全部「明日でOK」 | 4 / 60秒 |
| 10 | 締切ドラゴン | 無害な「本日中」の炎を出し、縮んで「来週で大丈夫です」 | 4 / 60秒 |

配置は元の10レイアウトを使用し、距離・遮蔽物・形状・大きさ・数・控えめな動きで変化をつける。キャラはPrimitiveと3D文字で作り、外部の画像や3Dモデルに依存しない。ケーブルや紙、門、ドラゴンの羽など、形状・反応はキャラごとに別実装とする。

解決済みのキャラは命中判定を外し、ほかの対象の射撃を妨げない。同じ解決済みキャラから繰り返し加点できない。分裂は演出だけで、新たな必須対象を増やさない。

## 3. 画面と遷移

- タイトル：保存されたステージからSTART、ステージ選択、図鑑、設定。
- ステージ選択：クリアで次を解放し、解放済みステージは再選択可能。
- ゲーム：目標・説明・進捗・時間・スコア・残弾と既存の操作UI。設定とタイトルへの中断導線を用意する。
- 決着：最後の解決後は2.2秒間3D画面を保持し、オチを文字で見せる。キャラの変化と同時に決着音を鳴らす。
- 結果：クリア・時間切れ、オチ、スコア・命中率・コンボを表示。次へ・同じステージの再挑戦・タイトルへをつなぐ。最終クリア後は達成メッセージとステージ1からの再プレイを表示する。

設定・ステージ選択・図鑑はシートで表示する。プレイ中に設定を開くとタイマー・移動・コンボの経過を停止し、閉じると再開する。通常のバックグラウンド移行では以前と同じく実経過時間で制限時間を精算する。

## 4. 再プレイと保存

UserDefaultsを使用する。設定の既存キー`shotSoundEnabled`・`shotSoundVolume`は継承する。

- `shotSoundStyle`：発砲音の系統。`hapticsEnabled`：振動。
- `progress.cleared`・`progress.current`：クリア済みと再開するステージ。次の解放範囲はクリア済み情報から求める。
- `progress.seen`・`progress.endings`：出会った敵と発見したオチ。
- `progress.visits`：再プレイ時に装飾・オチを切り替えるための訪問回数。

解放範囲外のステージ開始を拒否する。読み込んだ番号は範囲確認し、未知の図鑑キーは除外する。出会いは開始時、オチは1体の解決時、ステージクリアは最後の命中時に保存する。決着演出中の中断でも獲得済み内容を消さない。各ステージの途中の弾数・残り時間・命中途中の状態は保存せず、再挑戦時に初期化する。

再プレイでは左右反転と±0.2m以内の配置変化を行う。遮蔽物・重なり・範囲を確認し、不適切なら元の位置を使う。オチは1種につき3個、全30個。訪問ごとに順番に切り替え、3回の再プレイで同じオチだけが続かないようにする。

## 5. 音と振動

発砲3系統×3音、材質別命中6音、通常決着と最終決着の2音、計17音を同梱する。すべて独自合成した44.1kHz・16bit・モノラルPCMで、生成スクリプトに非無音・形式・数の検査を残す。

AVAudioPlayerで事前読込みする。発砲音は選択中の系統からランダムに選び、直前と同じ番号を避ける。発砲・命中・決着はそれぞれ最大1音に限定し、波形のピークと役割別のゲインを抑える。決着音の再生中は発砲音を小さくする。

発砲成立時に発砲音、実際のRay命中が成立した時に材質音、最終形への変化が完成した時に決着音を鳴らす。空撃ち・時間切れ・設定中の操作は無音。SEオフと音量0は全SEに適用する。端末の消音モード・システム音量に従う。振動は端末の標準フィードバックAPIを使用し、設定でオフにできる。

ボイスは導入しない。オチはゲーム中・結果・図鑑で文字として伝える。動きを減らすアクセシビリティ設定では揺れと粒子を抑え、VoiceOver利用中は命中時の反応文を通知する。

## 6. 実装の分担

- `Stage.swift`：敵の種類・説明・オチ、配置、制限時間、安全な配置変化。
- `GameState.swift`・`ProgressStore.swift`：進行、命中と解決、タイマー、設定中の停止、保存。
- `GameWorld.swift`・`EnemyVisual.swift`：既存FPS描画・移動・Ray判定と、敵ごとの形状・動き・反応。
- `Views.swift`・`LibraryViews.swift`：タイトル・ゲーム・結果・設定・ステージ選択・図鑑。
- `ShotSound.swift`・`Audio/`・`scripts/generate_sounds.py`：役割別の音、連続重複を避ける選択、同梱音源と再生成。

新しい依存関係、通信、サーバー、実課金、購入ボタン、月替わり配信、将来向けの汎用販売基盤は追加しない。HTMLモックは初期の静的デザイン資料として保持し、現行動作はiOS版を基準にする。

## 7. 検証と未確認事項

Xcode 26.5 / iPhone 17 / iOS 26.5 Simulatorを使用する。機能テストで全10種類の実際の命中と解決・最終再開、保存、配置変化、音の選択と再生状態、移動を検証する。UIテストで設定・図鑑・進行の再起動後の反映、通常操作でのステージ遷移、時間切れと再挑戦を検証する。解決前後20枚と各画面の画像を確認する。

未確認：実機の聴感・再生遅延・消音スイッチ・振動・性能、VoiceOverや動きを減らす設定の実機操作、人が全10ステージを通して遊んだ際の難易度と満足感。音源・モデルに無音の仮素材や未配置の必須素材はない。今後の美術や音の調整は任意の改善とする。
