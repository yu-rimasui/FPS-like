# FPSごっこ

> **戦わなくていいFPS。**

**FPSごっこ** は、日常のイラッを撃つとアホな解決をする、ゆるいiOSゲームです。人物関係や長い物語はありません。

敵に撃たれません。

ゲームオーバーもありません。

通知、ふとん、読み込み、締切。日常の困りごとがコミカルなキャラになっています。

FPSの「怖い部分」をすべて取り除き、

**撃つ・狙う・リロードする**

そんな「FPSやってる感」だけを楽しむゲームです。

## 現在の状態

SwiftUI＋RealityKitによるiPhone向けゲームです。既存の訓練場とFPS視点・移動・射撃・即時リロードを活かし、10種類の困りごとを解決します。1ステージの制限時間は35〜60秒です。

- 命中するたび見た目が変わり、各キャラの必要回数を満たすと解決します。全員を解決した後は2.2秒間オチを見届け、結果から次へ進めます。時間切れは再挑戦、最終クリア後は最初から再プレイ・タイトル復帰ができます。
- タイトルにステージ選択と図鑑を用意しています。クリアで次を解放し、解放済みステージは選び直せます。STARTは保存されたステージから再開します。
- UserDefaultsに解放・クリア・出会った敵・発見したオチを保存します。オチは各敵3種、計30種。1体解決するたびに記録し、中断や失敗で獲得済みの内容を消しません。
- 再プレイは配置を反転・小幅に変化させ、装飾とオチも切り替えます。遮蔽物・範囲・重なりを確認し、危険な候補は元の配置に戻します。
- 設定にはSEのオン／オフ・音量・発砲音3系統の選択と試聴・振動があります。設定中は時間と移動を止めます。消音モードを尊重し、視差・動きの軽減設定では揺れや粒子を抑えます。オチは画面の文字と図鑑で読めます。ボイスはありません。

### 全10ステージ

| Stage | 困りごと | 命中・解決の変化 | 1体の必要回数 / 制限時間 |
| --- | --- | --- | --- |
| 1 | 通知スライム | 赤いバッジが弾けて「静かですね」 | 1 / 35秒 |
| 2 | あと5分ふとん | ふくらんで立ち上がり「出勤します…」 | 2 / 40秒 |
| 3 | ぐるぐる読み込み | 100％になって「特に何もありませんでした」 | 3 / 45秒 |
| 4 | 絡まるケーブル蛇 | 徐々にほどけて、きれいな輪に | 3 / 45秒 |
| 5 | 未読メールゴーレム | 紙が舞い、全部「承知しました」 | 3 / 50秒 |
| 6 | 月曜カレンダー | 曜日が進み、金曜にサングラス | 4 / 50秒 |
| 7 | 充電1％ロボ | 充電され、満タンでこちらも充電 | 4 / 55秒 |
| 8 | パスワード門番 | 条件を増やした末に「顔パスでどうぞ」 | 4 / 55秒 |
| 9 | ちょっとだけタスク | 見た目が分裂し、全部「明日でOK」 | 4 / 60秒 |
| 10 | 締切ドラゴン | 無害な「本日中」の炎から、小さくなって「来週で大丈夫です」 | 4 / 60秒 |

ステージ1は元の訓練場の配置を使用し、以降は距離・遮蔽物・大きさ・動き・数が変わります。分裂する紙やタスクは演出で、追加のクリア対象を無限生成しません。18発、命中+100点、命中率・コンボはステージごとに集計します。

### 同梱SE

`app/FPSPretend/Audio/`に独自合成した17音を同梱します。発砲はポップ・おもちゃ・やわらかの各3音から、直前と異なる音を選びます。命中はゲル・布・電子・ゴム・紙・金属の6種、決着は通常と最終クリアの2種です。

AVAudioPlayerで事前読込みし、同時再生は発砲・命中・決着の各1音まで。ピークと役割別の音量を抑え、決着中は発砲音を小さくします。外した発砲には発砲音のみ、空撃ち・設定中・時間切れには音を出しません。追加依存・外部素材・アプリ内通信・実課金・購入ボタンはありません。

音源を再生成するときは、標準Pythonで `python3 scripts/generate_sounds.py` を実行します。生成時に非無音・PCM形式・ファイル数を検査します。

## iOSアプリの起動・検証

`app/FPSPretend.xcodeproj`をXcodeで開き、`FPSPretend` schemeとiPhone Simulatorを選んでRunします。対応はiOS 17以降・iPhone・縦画面です。実機で実行する場合はSigningのTeamと必要に応じてBundle Identifierを設定してください。

```sh
xcodebuild -project app/FPSPretend.xcodeproj -scheme FPSPretend \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/TryFPS-build CODE_SIGNING_ALLOWED=NO build

# 利用可能なiPhone Simulator名に置き換えて実行
xcodebuild -project app/FPSPretend.xcodeproj -scheme FPSPretend \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath /tmp/TryFPS-build -parallel-testing-enabled NO \
  CODE_SIGNING_ALLOWED=NO test
```

テストは7件の機能テストと4件のUIテストです。全10種類の実際のRay命中・解決前後の画像、最終クリア後の再開、ランダム選択、配置の範囲、音の再生・音量・消音・空撃ち、設定・図鑑・進行の保存、時間切れと再挑戦を確認します。テストの保存領域は機能テストごとに分離しています。

Simulatorでの検証と実機性能は区別しています。実機での60FPS・起動速度は未計測です。

## モックの確認方法

[UIデザインモック](mock/html/index.html)をブラウザで開いてください。Tailwind CSSとGoogle Fontsを外部から読み込むため、インターネット接続が必要です。

ローカルサーバーを使う場合は、リポジトリのルートで実行します。

```sh
python3 -m http.server 8791 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8791/mock/html/index.html> を開きます。終了は `Ctrl+C` です。

# コンセプト

戦わなくていいFPS。

物語や役割設定はなく、自由に遊べる訓練場で日常の困りごとを撃って解決します。

通知が静かになり、月曜が金曜になり、締切が来週になります。操作・音・短いオチで、気軽に「FPSやってる感」を味わえます。

---

# ゲーム概要

プレイヤーはFPSの操作と、困りごとが解消する反応を楽しみます。

- 移動
- 視点操作
- 射撃
- リロード

敵AIは存在しません。

ゲームオーバーもありません。

安心して「FPSごっこ」ができます。

---

# 開発目的

このプロジェクトの目的は2つあります。

## 1. RealityKitを学ぶ

ゲーム制作経験がないため、

小さく完成させながらRealityKitを学ぶ教材として開発します。

## 2. 自分が遊びたいゲームを作る

市場調査から始めるのではなく、

「自分だったら遊びたい」

と思えるゲームを完成させます。
