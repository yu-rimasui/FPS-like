# 業務設計書

2026-10-23の修正仕様。SwiftUI・RealityKitの既存実装を利用し、初期人形を使った全5ステージとする。以前の10種類のキャラクター仕様は末尾の履歴を参照。

## 1. 遊びの基本

一人称カメラ、スワイプ視点、ジョイスティック移動、18発、即時リロード、命中+100点、命中率、2秒以内の連続命中コンボを維持する。プレイヤーへの攻撃・ダメージ・流血はない。射撃は最初に当たった物体のみ命中する。

## 2. 全5ステージ

| Stage | 人形と動き | 障害物 | 必要命中 / 制限時間 |
| --- | --- | --- | --- |
| 1 | 3体：横倒し移動2・歩行1 | 壁 | 各5回・合計15回 / 60秒 |
| 2 | 4体：歩行2・走行2 | 回る風車の羽 | 各5回・合計20回 / 60秒 |
| 3 | 4体：ダンス | 転がるボール | 各5回・合計20回 / 60秒 |
| 4 | 4体：笑い転げながら移動 | 迷路 | 各5回・合計20回 / 60秒 |
| 5 | 4体：スキップ2・飛行2 | 落下する隕石 | 各5回・合計20回 / 60秒 |

60秒以内に全員を消すとクリアし、60秒経過は未クリアとする。最後の命中より先に期限へ達した場合は時間切れを優先し、二重クリアしない。開始・再挑戦・次ステージでは時間・ヒット数・弾数・色をリセットする。

飽きにくい短い操作量として計算基準N=15を採用。個体上限は `ceil(N / 人形数 / 5) × 5` 回で、現構成では各5回。上限で姿と命中判定が消え、ステージ中の復活はない。人形が残っている限り、合計N回だけではクリアしない。

形状・比率は初期コミット `4744d69` の `makeTarget` にある頭・胴・四肢の6個の直方体と目を再利用する。寸法は変えず、部位の関節と全体の姿勢を動かす。歩行と走行は速度・手足の周期・振り幅を区別する。ダンスはリズムのある手足と体の揺れ、笑い転げは揺れ・回転を伴う移動、スキップは跳ね、飛行は地面から離れた高さで表現する。命中判定も姿勢・手足・位置に追従する。

全人形がステージ内を移動し、横倒しの2体も姿勢を保って動く。歩行・走行・ダンス・転がり・スキップ・飛行の局所アニメーションと、水平面の移動を分ける。既存の境界・障害物判定を人形にも使い、体の最大幅を考慮した余白を確保する。0.5mの隣接点を簡単な幅優先探索でつなぎ、届く範囲の遠い目的地を個体別に選ぶ。移動量を制限して瞬間移動を防ぎ、曲がり角を斜めに省略しない。動く障害物はその移動範囲を避ける。

迷路の壁は添付俯瞰図の座標から17本に変換し、外周・T字・L字の接続を重ねて隙間を防ぐ。壁は同じメッシュからコライダーを生成する。迷路ステージは左右反転せず、開始位置は図の下側 `(1.7, 1.6, 3.8)`、カメラの一人称方式は維持する。

人形の基本色は淡いグリーン・ピンク・ブルーから開始ごとに個体別にランダム選択する。命中した個体のみRGBを同じ比率で濃くし、最後の命中から1秒で元の色へ戻す。色と動きはワールドのフレーム更新で処理し、遅延タスクや個別タイマーを追加しない。

障害物は移動と射撃を遮り、接触・落下ダメージは追加しない。風車の羽は回転、ボールは回転しながら往復、隕石は落下を繰り返す。迷路と壁は静止する。

## 3. 画面と遷移

タイトルのSTART・ステージ選択・図鑑・設定を維持する。クリアで次を解放し、結果から次へ・再挑戦・タイトルへ進む。全員消滅後は最大2.2秒の決着画面を保持し、「結果へ」で省略できる。最終ステージでは達成表示からステージ1を再開できる。

設定画面中はタイマー・移動・コンボを停止する。バックグラウンド移行では実経過時間で期限を精算する。命中色の期限も実経過時間を使う。古いワールドを停止・破棄してから次のワールドを作り、古い描画や射撃が次ステージに作用しないようにする。

## 4. 再プレイと保存

既存のUserDefaultsキーを維持する。`progress.cleared`・`progress.current`・`progress.seen`・`progress.endings`・`progress.visits`を5ステージの範囲で読み込む。旧10ステージの保存から有効な先頭5件と訪問回数を引き継ぎ、全消去はしない。

再プレイ時は左右反転（迷路の壁は固定）と人形の±0.2mの配置変化を維持する。範囲・障害物・重なりを確認し、不適切なら元位置を使う。オチは1ステージ3個、計15個。発見・解放の保存と再挑戦時の途中状態リセットを維持する。

## 5. 音・アクセシビリティ

既存の音源・音量・消音・振動・発砲スタイル・同時発音制限を維持し、新規音源は追加しない。人形への命中は布の音を使い、命中数の節目と消滅・最終クリアでは既存の効果音を使う。VoiceOverへの反応文の通知を維持する。動きを減らす設定では体の揺れ・手足・跳ねを抑え、移動や障害物のゲーム上必要な動作は続ける。

## 6. 実装と検証

- `Stage.swift`：人形の種類・動き・配置・障害物・60秒・個体上限。
- `EnemyVisual.swift`・`GameWorld.swift`：初期形状・動作・命中色・消滅・障害物・Ray判定・移動。
- `GameState.swift`・`ProgressStore.swift`：進行・期限・命中数・一時停止・保存。
- `Views.swift`・`LibraryViews.swift`：5ステージ表示・進捗・結果・図鑑。
- 既存の`GameTests.swift`・`FlowTests.swift`：仕様・形状・色の期限・消滅・競合・切替・保存・描画・設定・時間切れ。

新しい依存、通信、課金、汎用基盤を追加しない。HTMLモック、Xcodeの改名、既存の音源と音生成スクリプトは今回の変更対象に含めない。

今回の検証結果はREADMEおよび作業報告を参照。実機性能・実機の聴感・VoiceOver操作、人が通しで遊んだ際の難易度と飽きにくさは機械テストでは保証しない。
