# 敵とコメント一覧 — ゆーり編集用

「ゆーり修正案」欄を自由に書き換えてください。この一覧への編集は、アプリへ自動反映されません。修正後に反映するための原稿です。

## 決まっている変更

- ステージ2：各敵の100％到達時のコメントを「起きた！！」に固定。
- ステージ3：各敵の100％到達時のコメントを「読み込めた」に固定。
- クリア後のオチは、各ステージ3種類を維持。既存の仕組みは訪問ごとの順番切替です。
- 「きれいな輪になりました」は要修正。「ほどいたら、ただの輪でした」は残す。
- Stage Clearを含む残りのコピーは、ゆーりの修正待ち。

## 各敵のコメント

進捗％はステージ全体ではなく、各1体への命中回数に対する割合です。画面中央の「100％コメント」と、結果画面・図鑑の「オチ」はステージ2・3では別の文言になります。

3D文字は敵の近くに付く短い表示です。残数・％の数字、進捗バー、チェック記号は別に表示されます。

## Stage Clear・結果画面

見出しの `/` は改行位置です。オチの本文は各ステージの「オチ1〜3」を使います。

| 表示場所 | 現在の文言 | ゆーり修正案 |
| --- | --- | --- |
| 通常クリア見出し | Stage / Clear! | |
| 全ステージクリア見出し | 全10ステージ / クリア！ | |
| 時間切れ見出し | ひと休み | |
| 通常クリアの説明 | オチを図鑑に記録しました。 | |
| 最終クリアの説明 | 日常のイラッ、全10種解決。おつかれさまでした！ | |
| 共通の目標（自動差し替え） | 合計{必要命中}回の命中で、{体数}体をすっきり | |
| 達成数（自動差し替え） | 解決 {解決数}/{体数} ・ 命中 {命中数} | |
| 集計の名前 | スコア / SCORE、命中率 / %、コンボ / MAX | |

## 文言の反映先

- `app/FPSPretend/Stage.swift`：敵の名前・説明・進行コメント・100％コメント・オチ・目標文。
- `app/FPSPretend/EnemyVisual.swift`：敵に付く3D文字。
- `app/FPSPretend/Views.swift`：Stage Clear・結果画面・ボタン。
- `app/FPSPretend/LibraryViews.swift`：図鑑は上記のオチをそのまま表示。
