# FPSごっこ

> **戦わなくていいFPS。**

**FPSごっこ** は、動く人形を狙う、ゆるいiOSゲームです。人物関係や長い物語はありません。

敵に撃たれません。

ゲームオーバーもありません。

歩く・走る・踊る・笑い転げる・スキップ・飛行。初期モデルと同じ形と比率の人形が登場します。

FPSの「怖い部分」をすべて取り除き、

**撃つ・狙う・リロードする**

そんな「FPSやってる感」だけを楽しむゲームです。

## 現在の状態

SwiftUI＋RealityKitによる全5ステージのiPhone向けゲームです。既存のFPS視点・移動・射撃・即時リロードを継承します。

- 各人形に5回命中すると姿と命中判定が消え、全員が消えるとクリアします。60秒経過は未クリアで、再挑戦できます。ステージ開始時に残り時間・命中数・弾数を初期化します。
- 基本色は淡いグリーン・ピンク・ブルーから個体ごとにランダムに選びます。命中した人形だけ同じ色味のまま1秒間濃くし、再命中したら最後の命中から1秒後に戻します。
- 個体上限は `ceil(N / 人形数 / 5) × 5` 回です。短く遊べる回数として計算基準Nは15、実際のクリア条件は合計N回ではなく全人形の消滅です。
- ステージ選択の名前は障害物名です。図鑑は横倒し・歩行・走行・ダンス・笑い転げ・スキップ・飛行の全7種類に分け、出会うとクスッとする説明を読めます。各説明の左に正方形の動く3Dプレビューを表示し、淡い3色からランダムに選びます。既存の人形・動作をそのまま使い、未発見の人形は表示しません。図鑑のオチ表示・収集数は廃止し、既存の出会いの保存から解放状態を引き継ぎます。
- 命中・消滅時は、全人形共通の「命中！」「ヒット！」「当たった！」「ナイスショット！」「お見事！」から毎回ランダムに表示します。休憩などのテーマは付けず、クリア結果には最後の命中コメントを引き継ぎます。時間切れは「タイムアップ」と表示します。
- 最大2.2秒の決着から結果・次へ・再挑戦・最終クリア後の再プレイを維持します。旧10ステージの保存は有効な先頭5ステージ分を引き継ぎます。
- SE・音量・発砲音・振動設定を維持します。設定画面中は時間と移動を止めます。動きを減らす設定では手足の揺れや跳ねを抑えますが、移動・風車・ボールなどゲーム上の動作は維持します。

### 全5ステージ

| Stage | 人形と動き | 障害物 | 必要命中 / 制限時間 |
| --- | --- | --- | --- |
| 1 | 3体：横倒し移動2・歩行1 | 壁 | 各5回・合計15回 / 60秒 |
| 2 | 4体：歩行2・走行2 | 回る風車の羽 | 各5回・合計20回 / 60秒 |
| 3 | 4体：ダンス | 転がるボール | 各5回・合計20回 / 60秒 |
| 4 | 4体：笑い転げながら移動 | 迷路 | 各5回・合計20回 / 60秒 |
| 5 | 4体：スキップ2・飛行2 | 落下する隕石 | 各5回・合計20回 / 60秒 |

障害物は移動と射撃を遮り、接触・落下によるダメージはありません。再プレイ時の左右反転・小幅な配置変化を維持します（迷路の壁と開始位置は添付図に合わせて固定）。人形の形状はコミット `4744d69` の6個の直方体と目の寸法を再利用し、歩行・走行では手足の振り幅・周期・移動速度を変えます。命中判定は動く人形の部位に追従します。18発、命中+100点、命中率・コンボはステージごとに集計します。

全人形は姿勢や手足の動作を保ちながら前後左右へ移動します。通れる0.5m間隔の点を既存の衝突判定でつなぎ、個体ごとに遠方の目的地と経路を選びます。曲がり角は区切って進み、行き止まりからも通路へ引き返します。動く障害物は移動範囲を避けて通ります。迷路は添付された俯瞰図から内壁17本を配置し、継ぎ目を重ねて接続、図の下側から一人称視点で開始します。

[旧・敵とコメント一覧](docs/敵とコメント一覧.md)は以前の10種類の仕様資料です。現行の人形・コメントは `app/FPSPretend/Stage.swift` を参照してください。

### 同梱SE

`app/FPSPretend/Audio/`に独自合成した30音を同梱します。発砲はポップ・おもちゃ・やわらかの各3音から、直前と異なる音を選びます。命中はゲル・布・電子・ゴム・紙・金属の各3音から連続重複を避けて選びます。節目の短いアクセント1音、決着は通常と最終クリアの2音です。従来の音源は保持しています。

AVAudioPlayerで事前読込みし、発砲と命中は各2音まで余韻を残し、節目と決着は各1音まで（合計最大6音）。波形のピークと役割別の音量を抑え、決着中は発砲音を小さくします。外した発砲には発砲音のみ、空撃ち・設定中・時間切れには音を出しません。追加依存・外部素材・アプリ内通信・実課金・購入ボタンはありません。

音源を再生成するときは、標準Pythonで `python3 scripts/generate_sounds.py` を実行します。生成時に非無音・PCM形式・ファイル数を検査します。

## iOSアプリの起動・検証

`app/fps-like.xcodeproj`をXcodeで開き、`fps-like` schemeとiPhone Simulatorを選んでRunします。対応はiOS 17以降・iPhone・縦画面です。実機で実行する場合はSigningのTeamと必要に応じてBundle Identifierを設定してください。

```sh
xcodebuild -project app/fps-like.xcodeproj -scheme fps-like \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/TryFPS-build CODE_SIGNING_ALLOWED=NO build

# 利用可能なiPhone Simulator名に置き換えて実行
xcodebuild -project app/fps-like.xcodeproj -scheme fps-like \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath /tmp/TryFPS-build -parallel-testing-enabled NO \
  CODE_SIGNING_ALLOWED=NO test
```

既存の機能・描画・UIテストで、全5ステージの命中と消滅・最終再開、初期モデルの寸法、動きの違い、色の復帰と連続命中、時間切れと最終命中の競合、前ステージからの処理漏れ、配置・障害物・保存・SEを確認します。機能テストの保存領域はテストごとに分離しています。

## モックの確認方法

[UIデザインモック](mock/html/index.html)をブラウザで開いてください。Tailwind CSSとGoogle Fontsを外部から読み込むため、インターネット接続が必要です。

ローカルサーバーを使う場合は、リポジトリのルートで実行します。

```sh
python3 -m http.server 8791 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8791/mock/html/index.html> を開きます。終了は `Ctrl+C` です。
