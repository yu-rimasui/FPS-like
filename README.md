# FPSごっこ

> **「弟が全部倒しといたから。」**

**FPSごっこ** は、FPSをやったことがない姉が「FPSやってるよ！」と冗談で言いたくて作る、ゆるいiOSゲームです。

敵に撃たれません。

ゲームオーバーもありません。

敵は最初から全員倒れています。

FPSの「怖い部分」をすべて取り除き、

**撃つ・狙う・リロードする**

そんな「FPSやってる感」だけを楽しむゲームです。

## 現在の状態

現在はUIデザインモックの段階です。タイトル・ゲーム画面（HUD）・リザルトの3画面をHTMLとTailwind CSSで作成しています。

- 390 × 844の固定サイズで3画面を比較できます。
- ボタン・数値は表示用です。ゲームロジック、画面遷移、データ保存はありません。
- iOSアプリ本体は未実装です。以下のゲーム仕様・技術スタックは今後のMVP開発方針です。

## モックの確認方法

[UIデザインモック](mock/html/index.html)をブラウザで開いてください。Tailwind CSSとGoogle Fontsを外部から読み込むため、インターネット接続が必要です。

ローカルサーバーを使う場合は、リポジトリのルートで実行します。

```sh
python3 -m http.server 8791 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8791/mock/html/index.html> を開きます。終了は `Ctrl+C` です。

# コンセプト

ある日。

ゲーム音痴な姉は、弟が毎日FPSを遊んでいる姿を見て思いました。

> 「私もFPSやってみたい。」

でも実際に遊ぶと、

- 敵が怖い
- 急に撃たれる
- 何が起きているか分からない

開始5秒で終了。

すると弟が一言。

> 「じゃあ敵全部倒しといたから。」

そこから始まる、

世界一平和なFPS。

---

# ゲーム概要

プレイヤーはFPSの操作だけを楽しみます。

- 移動
- 視点操作
- 射撃
- リロード
- 武器変更

敵AIは存在しません。

ゲームオーバーもありません。

安心して「FPSごっこ」ができます。

---

# 開発目的

このプロジェクトの目的は2つあります。

## 1. SpriteKitを学ぶ

ゲーム制作経験がないため、

小さく完成させながらSpriteKitを学ぶ教材として開発します。

## 2. 自分が遊びたいゲームを作る

市場調査から始めるのではなく、

「自分だったら遊びたい」

と思えるゲームを完成させます。
